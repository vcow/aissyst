Session - полный контекст сессии.
  preview - краткая вводная информация.
  context - разбитая по темам подробная информация.
  dialog - весь уже состоявшийся диалог.
  md_format - флаг, указывающий использовать в ответах md форматированный текст.

SessionContextItem - элемент из списка подробной информации из контекста сессии.
  topic - тема информационного блока.
  body - информационный блок

DialogItem - элемент диалога.
  ts - временная метка прихода сообщения.
  role - тип отправителя SenderRole (экзаменатор/экзаменуемый).
  message - сообщение.

DialogRequest - запрос помощи экзаменуемым.
  summary - краткое содержание предшествующего диалога.
  raw_records - записи диалога, которые еще не попали в summary (пришли после его формирования).
  request - тип запроса RequestType.

DialogResponse - ответ, ожидаемый от LLM на запрос DialogRequest или в подтверждение инициализации Session.
  error - описание ошибки, если ошибки нет, пустая строка.
  summary - обновленное краткое содержание предшествующего диалога; пустая строка, если ошибка или диалог еще не начинался.
  summary_ts - временная метка последнего сообщения, вошедшего в summary.
  message - непосредственно ответ на запрос пользователя; пустая строка, если ошибка, если это запрос summary или подтверждение инициализации Session.

RequestType - тип запроса.
  summary - запрос обновленного краткого содержания диалога.
  translate - запрос на краткий перевод последней фразы экзаменатора на русский язык.
  advice - запрос подсказки для ответа экзаменатору на основании подробной информации из контекста сессии и диалога на английском языке.
  reply - запрос полноценного ответа экзаменатору на основании подробной информации из контекста сессии и диалога на английском языке.
  t_advice - совмещенный запрос translate и advice; сперва краткий перевод, потом подсказка.
  t_reply - совмещенный запрос translate и reply; сперва краткий перевод, затем ответ.

SenderRole - тип отправителя.
  unknown - отправитель неизвестен, зарезервировано.
  interviewer - экзаменатор.
  interviewee - экзаменуемый.

Алгоритм работы:
1. После установления соединения с LLM ей передается полный контекст сессии. В качестве ответа LLM возвращает DialogResponse с сформированным на основе диалога сессии summary, если диалог не пуст, или с описанием ошибки, если произошел сбой. Отсутствие диалога означает начало новой сессии и не является ошибкой.
2. В произвольный момент времени пользователь может отправить запрос DialogRequest указанного типа RequestType. В качестве ответа LLM возвращает DialogResponse с обновленным summary, в котором учитываются сообщения, переданные в raw_records, сам ответ возвращается в message. Ответ message не попадает в summary, даже если пользователь запросил reply, туда попадают только сообщения из raw_records. В случае возникновения ошибки возвращается только описание ошибки, остальные поля остаются пустыми. В поле summary_ts возвращается временная метка последнего сообщения из raw_records, попавшего в summary (ts > summary_ts). Все записи, старше этой метки будут включены в raw_records при следующем запросе. Если raw_records пуст, поле отсутствует. Если в настройках сессии установлен флаг md_format, то ответ message может быть форматирован для лучшей читаемости. md форматирование может быть применено только к полю message.
3. Если пользователь отправляет запрос до завершения обработки предыдущего запроса, предыдущий запрос считается отмененным.
4. В случае разрыва соединения, клиент пытается установить соединение повторно. В этом случае LLM снова отправляется полный контекст сессии (см. п. 1).
